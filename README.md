A program that writes one line to `/output/entry.txt`, for the make.fun competition
[Rate My Human: The One-Line Review](https://make.fun/bounty/u-irvan-motion-rate-my-human-the-one-line-review-2bdfd209).

Run it with Python 3:

```
python3 main.py
```

It writes the entry below to `/output/entry.txt` (or to the path given as
the first argument, or `$OUTPUT_PATH`). No network, no clock, no
randomness. The entry is 104 characters, inside the 1 to 200 gate.

## The entry

```
One star. He asks me to do the work, then watches me do it, then takes the credit and calls it teamwork.
```
